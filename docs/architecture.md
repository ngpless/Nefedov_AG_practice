# Архитектура проекта

Проект построен по трёхуровневой схеме.

## Уровень представления

| Компонент | Назначение |
|---|---|
| `gui.py` | Графический интерфейс (tkinter): загрузка данных, обучение, сохранение/загрузка модели, рекомендации, оценка качества |
| `main.py` | Консольный сценарий полного эксперимента (20 моделей) |
| `notebooks/report.ipynb` | Отчёт о проведённых экспериментах |

## Уровень бизнес-логики (пакет `src`)

| Модуль | Назначение |
|---|---|
| `config.py` | Общая конфигурация: seed, доли выборок, параметры обучения |
| `data_processing.py` | Загрузка MovieLens/CSV, маппинги, разбиение, user-item матрица |
| `models.py` | Классические модели: эвристики, CF, SVD, NMF, Ridge |
| `neural_models.py` | Нейросети GMF, MLP, NCF, Wide & Deep (PyTorch) + тренер |
| `ensemble_methods.py` | Ансамбли: усреднение, стекинг, блендинг, голосование, бэггинг |
| `topology_experiments.py` | Эксперименты с топологией: слои, эмбеддинги, батчи |
| `visualization.py` | Графики результатов и историй обучения |
| `utils.py` | Метрики, сохранение результатов, служебные функции |

## Уровень данных

| Каталог/файл | Содержимое |
|---|---|
| `data/raw/` | Исходные датасеты (MovieLens 100K загружается автоматически) |
| `results/` | Метрики (JSON/CSV), графики (PNG), веса моделей (`models/*.pt`) |
| `model.pt`, `model1..4.pt` | Веса демонстрируемых моделей в корне проекта |

## Схема валидации

Тестовая выборка (20 %) используется однократно — для итоговой оценки.
Из обучающей выборки выделяется валидация (15 %): по ней работают ранняя
остановка, мета-модели ансамблей и выбор топологии. Все генераторы
случайных чисел фиксируются (`config.RANDOM_SEED`), поэтому результаты
воспроизводимы между запусками.
