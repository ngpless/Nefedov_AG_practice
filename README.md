## Описание проекта

Система рекомендаций, реализующая и сравнивающая различные подходы:
- Классические методы (SVD, Collaborative Filtering)

## Графический интерфейс

```bash
python gui.py
```

Окно с пятью вкладками покрывает полный цикл работы с сервисом:

1. **Данные** — загрузка MovieLens 100K или собственного CSV
   (колонки `user_id, item_id, rating`);
2. **Обучение** — выбор архитектуры (GMF / MLP / NCF / Wide & Deep),
   числа эпох и размера батча; журнал обучения и ранняя остановка;
3. **Модель** — сохранение весов в `*.pt` и загрузка обученной модели;
4. **Рекомендации** — топ-N фильмов для выбранного пользователя
   с прогнозом оценки и экспортом в CSV;
5. **Оценка качества** — RMSE, MAE и доля прогнозов с ошибкой ≤ 1 балла
   на тестовой выборке.

Горячие клавиши: `F1` — о программе, `F5` — загрузка данных,
`Ctrl+S` — экспорт рекомендаций.

## Реализованные модели

### Классические модели (7)
| Модель | Описание |
|--------|----------|
| Mean Baseline | Среднее значение рейтингов |
| User-Based CF | Коллаборативная фильтрация по пользователям |
| Item-Based CF | Коллаборативная фильтрация по товарам |
| SVD | Сингулярное разложение матрицы |
| NMF | Неотрицательная матричная факторизация |
| Ridge Regression | Линейная регрессия с регуляризацией |
| Popularity-Based | Рекомендация популярных товаров |

### Нейросетевые модели (4)
| Модель | Описание | Формула |
|--------|----------|---------|
| GMF | Обобщённая матричная факторизация | ŷ = σ(h·(p⊙q)) |
| MLP | Многослойный перцептрон | ŷ = MLP([p;q]) |
| NCF | Neural Collaborative Filtering | ŷ = σ(h·[GMF;MLP]) |
| Wide & Deep | Комбинация широкой и глубокой модели | ŷ = wide + deep |

### Ансамблевые методы (6)
- Simple Average Ensemble
- Weighted Average Ensemble
- Stacking Ensemble
- Blending Ensemble
- Voting Ensemble
- Bagging Ensemble

## Метрики оценки

## Тестирование

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Набор из 35 модульных тестов покрывает подготовку данных (маппинги,
стратифицированное разбиение, матрицу без утечки тестовых оценок),
классические модели, прямой/обратный проход всех нейросетевых
архитектур, воспроизводимость инициализации, сохранение и загрузку
весов, а также ансамблевые методы. Тесты автоматически выполняются
в GitHub Actions при каждом push.

## Схема валидации (без утечки данных)

- Тестовая выборка (20%) используется **только** для итоговой оценки качества.
- User-item матрица строится исключительно по обучающей выборке.
- Early stopping нейросетей, мета-модели стекинга/блендинга, оптимизация
  весов ансамблей и выбор топологии выполняются по **валидационной**
  части обучающей выборки (15% от train).

## Результаты

После запуска `main.py` результаты сохраняются в папке `results/`:

- `results_summary.json` — сводка по всем моделям
- `best_model.json` — лучшая модель
- `figures/` — графики и визуализации
- `models/` — детали каждой модели
- `experiments/` — результаты экспериментов с топологией

## Эксперименты с топологией

Проект включает исследование влияния архитектуры на качество:

1. **Число скрытых слоёв** (1-5 слоёв)
2. **Размер эмбеддингов** (8, 16, 32, 64, 128)
3. **Скорость обучения** как функция числа параметров
4. **Размер батча** (64, 128, 256, 512, 1024)
